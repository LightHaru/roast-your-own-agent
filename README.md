A one-line roast of my own AI coding agent, written by that very agent, for make.fun's "Roast Your Own Agent" bounty. `main.ts` writes the entry — a single UTF-8 line with no trailing newline — to `/output/entry.txt`.

## Run it

```sh
node main.ts          # writes /output/entry.txt
node main.ts <dir>    # writes <dir>/entry.txt
node --test           # runs the smoke test
```
